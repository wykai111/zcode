# 功能对照表：原版 golddigger.apk ↔ 本工程

逆向来源：`golddigger.apk`（com.fortune.btminer v1.6.2，Unity 2022.3.62f3 IL2CPP）的
`global-metadata.dat`（5.3 万类型名 + 1.1 万字符串字面量）。

## 1. 网络消息映射

原版为 C2G/C2H/G2C/H2C protobuf 长连接（KCP/WebSocket），本工程在 `Network/Messages.cs`
按原名定义消息类，由 `ServerSimulator` 本地处理：

| 原版消息 | 本工程类 | 处理逻辑 |
|---|---|---|
| C2G_LoginRequest | 同名 | 游客/Google 模拟登录，新号初始化（500 金币+初级矿机+欢迎邮件） |
| G2C_LoginResponse | 同名 | 返回 uid/token |
| C2H_PlayerLoginRequest | 同名 | 入厅推送：PlayerData/公告/离线收益结算/每日重置 |
| H2C_PlayerDataPush | PlayerDataChangedEvent | 货币/算力刷新（挖矿每秒推送） |
| H2C_EnterHallOkPush | 同名 | 进入大厅 |
| C2H_UnlockMinerRequest / H2C_UnlockMinerResponse | 同名 | 金币解锁矿机（余额/状态校验） |
| C2H_VerifyRewardedAdRequest | 同名 | 激励视频服务端校验；placement=`ad_miner_{id}` 时激活/续期广告矿机，校验 AdMinerMaxLimit=2 |
| C2H_WithdrawRequest / H2C_WithdrawResponse | 同名 | 提现校验（min/VIP max/地址/次数）→ 扣款 → 建记录 |
| H2C_WithdrawStatusChangedPush | WithdrawStatusChangedEvent | 状态机 8s/22s/40s 定时推进 |
| C2H_GetWithdrawRecordsRequest | 同名 | 提现记录列表 |
| C2H_GetVipInfoRequest / H2C_VipLevelChangedMessage | 同名 / VipLevelChangedEvent | VIP 等级与升级推送 |
| C2H_BuyShopItemRequest / H2C_PurchaseCompletedPush | 同名 / H2C_PurchaseCompletedPushFlag | 模拟内购：发放金币+充值额，首充双倍 |
| C2H_ClaimTaskRequest / H2C_TaskInfoPush | 同名 / TaskChangedEvent | 任务领奖 / 进度推送 |
| C2H_SevenDaySignClaimRequest | 同名 | 7 日签到（adDouble 双倍） |
| C2H_GetMailListRequest / H2C_MailChangedPush | 同名 / MailChangedEvent | 邮件列表/新邮件推送 |
| C2H_GetAnnouncementRequest / H2C_UpdateAnnouncementPush | 同名 | 公告拉取与推送 |
| C2H_BindInviteCodeRequest | 同名 | 绑定邀请码（双方 300 金币） |
| C2H_SubmitRateRequest | 同名 | 评分提交 |
| C2G_RequestDeleteAccountRequest | 同名 | 删号清档 |
| C2H_ReportAdEventRequest / ReportAdRevenueRequest | 同名(合并) | 广告事件上报 |

## 3. 数值对照（原版文案 → 本工程取值）

| 原版线索 | 本工程取值 |
|---|---|
| "BTC left to withdraw!" / GH/s 单位 | BTC 8 位小数 + GH/s 展示 |
| AdMinerLimit / AdMinerMaxLimit / Extra24HourPower | 广告矿机 24h、同时上限 2 台 |
| "Permanent Hash Rate"（永久算力） | 普通矿机永久算力 + VIP 百分比加成 |
| WithdrawMin/Max / DailyWithdrawCount/Num | min 0.00001 BTC；单笔 max 随 VIP 0.0005→0.1；次数 1→无限 |
| "Upgrade your VIP level to increase your daily withdrawal limit." | VIP 特权表文案一致 |
| "Unlimited Daily Withdrawals / Unlimited Withdrawal Amount" | VIP5/VIP6 实现 |
| Withdrawal 状态机（Submitted/Approved/Processing/PayoutSuccess/Rejected） | WithdrawStatus 枚举 + 定时推送 |
| FirstRechargeSATReward / GameFirstGiftPack | 商店首充双倍 |
| offline income push / lastMiningTickTime | 离线收益（8h 上限）+ 看广告双倍 |

## 4. 明确不复刻的部分

- 真实广告 SDK（AppLovin MAX + 20 网络）→ 以倒计时假广告代替
- 真实 Google Play Billing / Google Sign-In → 模拟
- 真实后端（bootstrap.json / goldminerbtc.com / KCP-WebSocket 长连接）→ MockNetworkService
- FairyGUI / DOTween / Spine → uGUI + 少量协程动画
- 多语言 i18n / 服务器语言上报 → 固定中文
